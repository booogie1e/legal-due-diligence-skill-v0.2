# Legal Due Diligence Skill

**Version:** v0.2 (prototype / manual testing)

An evidence-led, project-configurable AI workflow for Chinese corporate ownership, voting-control and related-party due diligence. Written for learning and evaluation; **not legal advice or independently verified company data**.

## Contents
- `legal-due-diligence/SKILL.md` — workflow and mandatory A–F output.
- `legal-due-diligence/references/related_party_rules.md` — six-class **configurable banking-outsourcing screening profile** (not universal statutory law).
- `legal-due-diligence/references/evidence_protocol.md` — IDs, evidence status, cross-reference and source-conflict requirements.
- `legal-due-diligence/tests/test_cases.md` — five completely fictional scenarios.
- `legal-due-diligence/tests/acceptance_criteria.md` — manual pass/fail criteria.

## Getting started
1. Use an AI environment supporting Agent Skills / SKILL.md, or manually supply the Skill and both reference files to an AI assistant.
2. Set target, analysis date, available documents, and the active related-party profile.
3. Run a test case from `tests/test_cases.md` and compare the output with `tests/acceptance_criteria.md`.
4. Review all conclusions and original sources before any professional use.

## Safety
Never upload privileged client documents, nonpublic bank files, real personal data or confidential contract contents into this public repository. All examples are synthetic. Do not claim official checks unless conducted. Check Git history for secrets.

## Status
This project is a **prompt-driven prototype**, not an autonomous database scraper, a verified legal source engine, or a production-ready legal opinion system. Automated tests, Excel export, and real data connectors are not implemented.
